# AstraClicker-Beta

A simple and lightweight clicker game built with Python using the tkinter library. This was created as a personal milestone project for learning game logic and user interface design.

## Features
- **Click to Score:** Earn points with every click.
- **Upgrade System:** Increase your click power by purchasing upgrades (prices double with each purchase).
- **Fullscreen Mode:** Toggle fullscreen easily to immerse yourself in the game.
- **Clean Interface:** Simple dark/gray theme built completely with Python's built-in tkinter.

## How to Run

Make sure you have Python installed on your computer. Then, follow these steps:

1. Clone or download this repository.
2. Open your terminal or command prompt in the project folder.
3. Run the game using Python:
   ```bash
   python AstraClicker-Beta.py
(Note: Make sure to replace AstraClicker-Beta.py with your actual Python file name if it is different.)
